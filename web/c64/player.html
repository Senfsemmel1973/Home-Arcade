Commodore 64

Spieldatei wird geprüft …

Programm wählen, dann im Spielfeld starten. Für eine andere Auswahl neu laden.

Controller verbinden, Seite fokussieren und eine Taste drücken.

Start und Steuerung

Im Spielfeld starten. Der C64 lädt die importierte Spieldatei automatisch. Ladebildschirme und mögliche Trainer beachten. Fragen gegebenenfalls mit N, Y, Return oder Space beantworten; den Bildschirmanweisungen folgen.

Xbox: linker Stick oder Steuerkreuz, A/untere Taste für Feuer, B für C64-SPACE; Start für Return, X für Space, View für Bildschirmtastatur. Tastatur im Joystick-Modus: Pfeile und Leertaste. Nach Bedienelementen wieder in die Spielfläche klicken.

C64-Tastatur und Ladebefehle

„C64-Tastatur aktivieren“ schaltet normale Tasten direkt zum C64 durch; nochmals drücken kehrt zum Joystick-Modus zurück. Return, F1/F3/F5/F7 und Run/Stop stehen zusätzlich oben bereit. Für Sonderzeichen kann die Bildschirmtastatur verwendet werden.

Bei D64, falls READY erscheint: LOAD"*",8,1 und Return, danach RUN und Return. Reset setzt den C64 zurück; „Neu laden / Autostart“ startet die Seite und Spieldatei frisch. Portwechsel wird sofort angewendet, falls noch keine spielinterne Umschaltung stattgefunden hat.
