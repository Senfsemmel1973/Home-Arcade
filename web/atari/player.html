Original-ROM wird lokal geladen …

Controller verbinden und eine Taste drücken.

Steuerung

Pfeiltasten bewegen · Leertaste Feuer / Sprung. R setzt die Konsole zurück, S wählt die Spielvariante. Nach Start in die Spielfläche klicken, wenn die Tastatur nicht reagiert.

Standard-Gamepad: linker Stick oder Steuerkreuz, Button 0 (meist A/untere Taste) für Feuer / Sprung. Button 9 (Start) für Reset, Button 8 (Select/View) für Game Select. Stick-Totzone: 0,3. Der rechte Stick wird nicht verwendet.

Start und Spielhinweise

„Starten“ drücken und bei Bedarf einmal in die Spielfläche klicken, um Audio freizugeben. Game Select vor Spielbeginn wählen. Vollbild benötigt eine Benutzeraktion; Escape verlässt natives Vollbild.

ROM unverändert. Kein Netplay, keine externen ROM-URLs. Ton und zehn Minuten Spielbetrieb müssen noch mit deinem Gerät geprüft werden.
